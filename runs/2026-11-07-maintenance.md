## 구현과 검토

- [원장 복구](../scripts/research.py): 운영체제 잠금, 원자 파일 교체, 미완료 작업 저널, 전후 상태 충돌 검사, 옛 배치의 최신 원장 덮어쓰기 방지. 공개 변경 이력 형식은 유지한다.
- [실행 경로](../scripts/run_pipeline.py): 입력 고정, 쓰기 전 연결 검사, 단계 기록, 동일 명령 재개, 완료 후 재실행에도 입력과 현재 원장 재검증.
- [연결 검사](../scripts/lineage.py)와 [명세](../data/research_lineage_20261106.json): 기존 문장·가설·행동을 복제·개작하지 않고 원래 ID와 위치에 연결한다.
- 독립 검토에서 명세가 실제 저장 대상과 다른 원장을 가리킬 때 사전검사만 통과하는 반례를 재현했다. runner가 실제 sources/claims 경로 일치를 쓰기 전에 강제하도록 수정하고 회귀 검사를 추가했다. 새 배치의 주장을 연결 명세 범위 밖에 두는 우회도 차단한다.
- 고정 배치의 줄바꿈 변환을 runner와 복구 저널이 다르게 판단하는 반례도 수정했다. 고정 배치는 정확한 바이트를 검사하고 Git 변환을 제외하며, 변환 시 저장 전에 명확한 복원 안내와 함께 중단한다. 원래 바이트를 복원하면 동일 작업 재개가 통과한다.
- 검토 기준은 설치된 원본 Anthropic PR Review Toolkit의 code-reviewer, pr-test-analyzer, silent-failure-hunter 지침이다. 실행 호스트는 Codex이며 다른 모델이나 Claude 실행 결과로 표시하지 않는다.

## 범위와 한계

검사는 원본 참조·유형·선언된 읽기 범위의 일관성을 확인한다. 근거의 의미상 충분성, 인과 추론, 전망의 정확도는 증명하지 않는다. 이번 명세는11월6일 주장12개·가설6개·행동9개를 대상으로 하며 기존432개 주장 전체의 행동 연결을 소급 검증하지 않는다.

잠금과 복구 저널은 같은 로컬 체크아웃 전용이다. 저널은 로컬에 보존하고 Git에서 제외한다. 기존 `history/*.json`의 공개 변경 이력과 runner의 계획·검증 기록은 게시한다. 프로세스 중단과 파일 저장 실패를 검사했으며 하드웨어 장애·전원 상실·클라우드 동기화 간 분산 트랜잭션은 보장하지 않는다. 상세 사용법은 [재실행·연결 검사 절차](../docs/REPLAY_AND_LINEAGE.md)에 있다.
