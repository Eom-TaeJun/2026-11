# 원문 귀속·교수형 설계·조건부 적용 독립 검토

2026-11-07. 역할 수정 담당·조건 적용 작성자와 다른 담당이 검토했다. 최종 결정과 반영 책임은 총괄이다.

## 범위

공개 원문 지도9개 카드, v2.2 역할 관련5개 파일, 세 그룹의 초기/후기 가설과15개 조건 적용을 읽었다. Future Markets의 상품 확대, Coase의 거래비용, Hermes의 연구 품질 기준3구간은 고정 공개 원문을 별도 조회했다. OIP 수식 자체의 명시는 작성자의 PDF10쪽 재확인에 의존했으며 독립 검토자가 PDF를 다시 읽은 범위로 세지 않는다.

## 발견과 수정 확인

| 항목 | 발견 | 반영·확인 |
|---|---|---|
| IR-01 귀속 | CARD01의 법적 비용0 미입증은 저자 명시 조건이 아님 | 분석자 한계로 옮기고 선택 재열람 범위로 한정 |
| IR-02 판단 범위 | CARD03/05 모형·분업 변경과 시장/사업 변경이 섞여 읽힐 수 있음 | decision_scope로 구분, 교수 명시 반전 기준 null 유지 |
| IR-03 초기/후기 | 한화 고용주·IDR는 초기부터 있었고 BNK 야간 기본제품은 초기 입장이 아니었음 | 고객을 바꾼 것처럼 쓰지 않고 초기 범위 유지·운영 분기 구체화로 교정 |
| 날짜 표현 | v2.2 문서가 과거 설계 읽기 기록을 이번으로 부름 | v2.1 기록과11월7일 재열람 링크 구분 |

수정된 공개 파일에서 반영을 재확인했다. 초기 가설 배열과 보존 파일이 동일하며 작성자의 해시 직렬화 형식도 확인했다. 알려진 비공개 저장소명·Drive ID·사용자 로컬 경로가 공개 분석에 복제됐는지 점검했다.

## 경제적 의미 검토

3그룹×5조건에서 기존 거래 이동과 이전 미성립 금융 접근, 고객 지급능력, 무료 묶음 경쟁, 현지 보험 책임, 토큰/은행현금, 보수/원금/손실을 구분했다. 기존+AI가 같은 결과를 내는 경우 온체인 투자와 새 고객 기회를 별도로 판단했다. 시간 조건과 내부/외부 상대비용을 다른 실험으로 다뤘다. 조건이 달라지면 확대·기존 레일·제휴·미진입 등 행동이 달라졌다.

이는 조건부 논리의 정성 검토다. 15개는 사전 조건을 알고 작성한 개발용 사례이고 블라인드 비교·예측 정확도·실제 유료 수요·법률 적합성 검증이 아니다. 교수의 개인 사고방식 재현 여부도 평가하지 않았다. 독립 검토의 동의는 추가 현실 증거가 아니다.
