# 금융환경 자료 수집

정책·경제·금융·기술에서 기업의 선택 조건을 바꾸는 변화는 무엇인가?

먼저 AGENTS.md와 PIPELINE.md를 읽는다.

## 입력

- 조사 질문서
- 기존 가설
- 기존 근거 원장

## 작업 지침

1. 중앙은행·감독기관·법령·통계·국제기구·연구기관·학술자료·최근 산업 보고서의 원문을 질문에 맞게 찾는다.
2. 금리·조달비, 규제·자본 제약, 고객 수요, 기술 비용·성능, 유통·경쟁구조로 변화 후보를 분류한다.
3. 새로운 자료와 실제 새로운 사건을 구분하고, 기존 지식의 변화 여부를 표시한다.
4. 검색 경로로 한국은행·금융위·금감원·BIS·IMF 등 관련 기관을 활용하되 대상과 질문에 맞게 선택한다. 목록 자체를 최신 자료를 읽었다는 증거로 제시하지 않는다.
5. 뉴스와 보고서의 중요한 주장은 가능하면 원통계·원규정·원연구로 추적한다.
6. 수집은 주요 판단을 바꿀 조건 중심으로 제한하고 접근 실패와 조사 공백을 남긴다.

## 산출물

- 환경 변화 후보
- 원문 근거 카드
- 이전 대비 변경분
- 추가 확인 질문

완료 조건: 각 주요 변화 후보의 출처·대상·시점·관측 범위와 확인하지 못한 부분이 기록되어야 한다.

규제를 조사할 때는 법률 성립·공포·초안·최종규칙·효력·신청접수·개별 인가·실제 운영을 각각 기록한다. 가장 최근에 찾은 자료와 기준일까지의 최신 상태를 전수 확인한 결과를 구분한다. 정책금리·실제 자산수익률, 실적·과거 전망·새 전망을 혼합하지 않는다. 규제와 거시 관측은 data/regulatory_watch.json 및 data/macro_observations.json의 해당 항목을 이어 쓴다.

출처·주장·주제 ID를 넘기고 핵심 원문 위치와 미확인을 보존한다. 다른 담당의 파일은 직접 덮어쓰지 않고 총괄에 변경 제안을 넘긴다.

국가별 제도·일정은 data/regulatory_regimes_2027.json 및 data/regulatory_calendar_2027.json과 연결한다. 조항별 효력·별도 전환·목표·시범 단계를 분리한다.


## 경제적 의견을 위한 역할 인계

초기 교수형의 핵심 가정과 판별 질문을 받아 어떤 비용·제약·정보·선택권이 실제 바뀌었는지 조사한다. 잠정 입장과 반대 경로의 자료를 함께 찾는다.

관련 없는 새 소식보다 결론을 가를 자료를 우선하고 사건·정책·기술 발표를 비용 감소나 반복 채택의 결과로 승격하지 않는다.
