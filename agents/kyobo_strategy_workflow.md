# 교보 미래전략 후속 연구의 에이전트 분업

이 문서는 기존 8개 논리 역할을 교보 과제에 배정하는 작업 지침이다. 상시 프로세스나 매매 에이전트가 아니다. 사용자가 정한 미래전략팀 관점이며 실제 회사 업무분장은 별도 확인한다.

## 입력

1. [사업안](../reports/18_kyobo_future_strategy_business_plan.md), [사업 원장](../data/kyobo_strategy_business_plan.json), STR-KY-01~05.
2. [그룹 거래](../reports/19_kyobo_group_rwa_deal_design.md), [레일·AI](../reports/20_kyobo_rails_agent_business.md), [자본·권한](../reports/21_kyobo_capital_and_permissions.md).
3. 출처 카드의 읽은 범위·시점·미확인과 최신 runs 기록. 기존 자료 전체 재수집부터 시작하지 않는다.

## 역할과 결과

| 담당 | 질문 | 넘길 결과 | 완료 기준 |
|---|---|---|---|
| 공식자료 수집 | 자본·인가·규칙·실적에서 실제 바뀐 사건은 무엇인가 | 원문 URL·선택 범위·사건/효력/관측일·source 초안 | 결정·납입·인정·지정·개별 업무·실운영 구분 |
| 자료 해석·권리 설계 | 누가 어떤 청구권을 갖고 누가 언제 현금을 지급하는가 | 한 거래의 권리·수금·배분·도산·회수와 미확인 | 자료의 판매액과 순채권·수익·원금을 구별 |
| 목적 적용·레일/AI | 같은 고객 업무에서 어떤 편익과 실제 지급자가 생기는가 | 기존/기존+AI/온체인/온체인+AI 비교·계약 보수·책임 | 발행자 준비금수익과 교보 서비스·투자 성과 구분 |
| 교수형 메커니즘 검토 | 희소한 자산·신용·유동성·책임을 누가 부담하며 경쟁 뒤 무엇이 남는가 | 강한 미래 가정·고객 행동·가격/채널 대응·반증 관측 | 특정 교수의 현재 견해로 귀속하지 않음 |
| 독립 검증 | 원권리·법인·날짜·자본·현금·비용을 잘못 합쳤는가 | 수정 요구와 근거, 미해결 질문 | 초안 작성자와 다른 담당이 핵심 논리를 확인 |
| 병합·기록 | 어떤 판단과 다음 행동이 달라졌는가 | ingest 묶음·사업/전략 ID·보고서·run | 이전 이력·원문·공개 경계 보존, 검증 후 원격 확인 |

## 반드시 남길 경계

- RCPS 결정과 납입·지정 인정자본, 3/4/8조 단계와 경과조치·별도 인가.
- 그룹 자료/주선 역할과 계열 기업신용·보증·자기 인수, 생명의 독립 ALM·투자심사.
- 저작권·이용권·판매정산채권·투자자 증권·토큰 표시, 양도·대항·항변·도산.
- 토큰 도착·전환·증권 현금·증거금 인정·출금·은행 최종 수취.
- AI 조회·권유·주문·출금·신용 권한, 취소와 이미 실행된 거래의 복구.
- 고객 편익과 교보 순기여, 내부 보수와 외부 수입, 준비금 요구와 실제 적립·부족.

확대는 반복 고객·실제 계약·수금·회수·총비용 후 기여로 판단한다. 신규 발행량·MOU·소스 수·에이전트 동의 수만으로 판단을 올리지 않는다. 최신 문서끼리 충돌하면 계약 범위·갱신 시점으로 해결할 때까지 충돌을 보존한다.
