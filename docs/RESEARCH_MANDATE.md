# 계속 사용할 금융환경·기관 전략 연구 방향

2026-11-03에 정리한 사용자의 연구 목적이다. 사용자 지정 관점을 보존하는 문서이며 회사의 내부 전략이나 확인된 직무 소관을 나타내지 않는다.

## 공통 순서

먼저 현재 금융환경을 탑다운으로 분석한다. 달러의 지급·가치저장·담보 역할, 금리·자금조달·유동성, 한국은행의 대응, RWA·토큰화·온체인 금융, AI 위임에 따른 고객 접점과 수익 분배를 연결한다. 이어서 2027년 초와 이후를 나누어 본다. 필요한 법·인가·권리·현금 레일·위임이 성립한 강한 가정을 명시하고, 그 세계의 고객 행동과 경쟁자의 대응까지 추론한다. 현재 미인가 상태만 반복해 미래 분석을 끝내지 않는다.

그다음 바텀업으로 실제 고객·기존 수익·자본·인가·계약·조직·운영을 확인한다. 새 사업의 성장 가능성과 기존 사업의 방어·디지털화를 함께 판단한다. 기존 방식+AI와 온체인+AI를 같은 고객 업무·권리·위험·총비용으로 비교한다.

## 세 기관의 분석 자리

**경남은행 본사:** 글로벌 디지털·달러 환경 → 한국은행과 국내 금융인프라 → 시중은행·지방은행 경쟁 → 지역기업·가맹점·공공자금·가계의 실제 업무로 좁힌다. 지역 관계와 신용·보증·외환·자금관리 강점을 유지하면서 일상적인 고객 접점을 만든다. 해외 범위는 실제 고객 통화·거래국·반복 수요가 있을 때 넓힌다.

**교보증권 미래전략팀:** 현재 증권업과 자본구조에서 출발해 종투사·초대형 IB로의 조건부 성장, 국내외 자산·자금·유통을 본다. 생명·문고의 역할과 데이터·계약 경계를 구분한다. 교보의 신뢰를 비정형 RWA의 권리·평가·정산·회수로 구체화한다. USDC/USDT 등 레일의 실제 계약·최종 현금을 추적하고, AI가 상품을 다양하게 조합할수록 필요한 원권리·중복담보·고객 적합성·사후관리와 투자 우선순위를 판단한다. 증권사를 은행 인가 보유자로 표현하지 않는다.

**한화생명 블록체인·신사업팀:** 생명보험의 보장·ALM·고객 기반과 증권·운용·은행·미국 청산 기능의 연결을 개별 법인 단위로 분석한다. UAE/아부다비, 인도네시아 Nobu와 방카슈랑스, 미국을 우선하되 기존 활동에서 중요한 다른 국가·업무를 추가한다. 젊은 인구·보장 공백은 실제 접근 가능 고객·지급 능력·유지·지급 경험으로 좁힌다. AI 에이전트에게 선택될 정보·실행·복구 서비스와 계약상 수익모델을 기획→운영→위험·경쟁→검증으로 전개한다.

## 교수형 검토와 기존 연구

공개 강의의 거래비용·위임·비교우위·포트폴리오·기업 경계·화폐와 권리의 질문을 기존 연구와 결합한다. 교수의 원래 설명, 기관의 주장, 개인적 해설, 이번 추론을 구분한다. 특정 교수의 현재 견해를 대신 말하지 않는다. 다른 해석과 반대 증거를 보존한다.

기존 라이브러리·채팅·작업물·10월 이후 GitHub 금융·경제 활동에서 원문 경로를 먼저 찾는다. 기간·범위가 불분명한 전수 조사 주장을 피하고, 확인한 범위와 접근 공백을 기록한다. 개인 자료는 탐색에 활용해도 공개 원문으로 재확인할 수 없는 비공개 내용·경로·계정정보를 이 저장소에 게시하지 않는다.

## 매번 남길 산출물

원문 카드(읽은 위치·요약·활용·의미·한계) → 사실·해석·가설 → 거시 지도 → 기관별 결정 → 다음 관측을 연결한다. 회사 발표·MOU·투자·인가·출시·반복 사용·매출·이익은 따로 적는다. 고객→계약→권리·자금→보수→비용·위험→회수의 흐름을 닫고 미확인 수치는 null로 둔다.

후속 작업의 출발점은 [통합 판단](../reports/15_strategy_decisions_and_validation.md), [결정 원장](../data/strategy_decisions_2027.json), [역할 명세](../agents/roles.json), [운영 절차](../PIPELINE.md)다. 이 지침은 지속 실행 서버·정기 수집·거래 실행을 설정하지 않는다.

## 2026-11-03 추가 방향: 국가 수요와 그룹 관점

한화생명 블록체인팀 관점에서 UAE·아부다비, 인도네시아 Nobu, 미국과 USDC·USDT 연결을 심화한다. 방카슈랑스는 사용자가 제시한 출발 아이디어이며 현지 상황에서 다른 고객 문제와 기회도 독립적으로 발굴한다. 같은 방법을 경남은행을 포함한 BNK금융지주, 증권·생명·문고를 포함한 교보그룹, 금융·산업을 포함한 한화그룹에 적용한다.

고객 접점·지급자·계약·현금·법인별 수입/비용·그룹 외부 기여·경쟁·위험·검증을 보존한다. 시장 규모·계열 소속만으로 고객·권한·자산·매출을 연결하지 않는다. [한화 사업안](../reports/22_hanwha_group_business_plan.md), [그룹 기회 발굴](../reports/25_group_country_opportunity_discovery.md), [반복 작업 지침](../agents/group_country_opportunity_workflow.md)에서 이어간다.

## 2026-11-04 추가 방향: 교수 Ondo 원문과 세 그룹의 선택

기존 강의의 원문·시점·계산 가정과 현재 공식 상품 조건을 구분하고 BlackRock·Ondo의 상품별 법인·권리·현금·보수와 경쟁/보완 관계를 비교한다. 이를 BNK·교보·한화의 실제 기반과 고객·수익·위험·판단 변경 관측에 연결한다. [통합 분석](../reports/29_tokenization_competition_group_strategy.md)과 [반복 작업 절차](../agents/position_comparison_workflow.md)를 출발점으로 삼는다.
