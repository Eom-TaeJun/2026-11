# KNX-S-005 · 외화예금안내

발행일: 미확인/동적 · 확인일: 2026-11-03

읽기 상태: **selected_sections**

읽은 위치: - 공식 HTML 90~106행: 특징·예수 가능 통화·법인 개설서류. 예금보험 법률 평가에는 사용하지 않음.

## 자료의 핵심 내용

법인 개설서류와 여러 외화의 예치, 동일 계좌의 최대 5개 통화 운용을 안내한다. 해외송금 등에 외화를 사용할 수 있다고 설명한다.

## 이번 연구에 활용한 내용

- 수출대금의 즉시 원화 환전 외에 외화 보유·지급 선택이 이미 존재
- 같은 통화 수취·지급의 일정 연결 가설

## 해석의 한계

- 무일자 일반 안내. 개별 예금의 만기·이자·출금 조건과 법인 온라인 기능은 별도 확인 필요.
- 외화 보유는 자동 환헤지 또는 손실 방지가 아니며 잔여 순노출·시점 불일치가 남는다.

## 연결된 주장

- **C-160 / institution_statement / active**: 경남은행의 외화예금 안내는 법인 개설과 동일 계좌의 여러 통화 운용, 외화의 해외송금 이용을 설명한다.
- **C-167 / hypothesis / active**: 외화 수취·지급 일정과 여신 만기를 함께 관리하면 불필요한 왕복 환전과 단기 차입을 줄일 여지가 있다.
