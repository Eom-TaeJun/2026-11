## 자료의 핵심 내용

ETC의0.65% adviser 보수와 한화운용의 sponsor 계약을 명시한다. 한화는 제외비용 외 펀드 비용과 해당 시 ETC 최소보수를 부담하고 ETC로부터 AUM 연동 보수를 받는다.

## 이번 연구에 활용한 내용

- 지급자·수취자·비용 부담을 닫아 교차상장 경제성을 판단한다.

## 해석의 한계

- 한화 보수율·최소보수액·실현수입은 이 절에 미공개다. 합본 전체와 계약 부속서·후속 변경은 읽지 않았다. KMCA에 그대로 적용하지 않는다.
- 2026-03-27 제출문서의 KDEF 선택 절. 2027 조건·한화 요율·최소보수·실현수입·KMCA 동일 적용은 확인하지 않음.

## 연결된 주장

- **C-253 / fact / active**: KDEF의 adviser는ETC이고 한화운용은 지수 제공자·sponsor다. 한화는 AUM 연동 보수와 일부 비용·해당 시 최소보수 의무를 가진다.0.65% 전액이 한화 매출은 아니다.
- **C-264 / hypothesis / active**: UAE의 우선 검증 대상은 실제 교차상장 ETF의 반복 고객·유동성·스폰서 순경제성이다. 토큰화는 별도 권리·허가·현금 조건에서 증분 효과를 실험한다.
- **C-339 / interpretation / active**: BlackRock/Ondo 비교를 세 그룹에 적용할 단위는 자산발굴·인수·운용·구조화·유통·은행현금·담보·사후관리의 계약 기능이다.
- **C-347 / hypothesis / active**: 한화는 인니의 보장·IDR 납입/청구, 미국 기관의 실제 지원 상품 사후처리, UAE 상품 공급·유통을 별도 계약으로 개선할 수 있다. 보험 의무와 자금·상품·청산의 손익을 하나의 온체인망으로 합치지 않아야 한다.
- **C-348 / interpretation / active**: 같은 원천 채권·펀드·담보의 포장을 늘려도 독립된 기초 현금흐름은 자동으로 증가하지 않는다. 맞춤 효용·위험배분과 총청구·레버리지·집중·기한 불일치를 분리해 평가해야 한다.
- **C-349 / hypothesis / active**: AI가 상품 탐색·조건 비교를 쉽게 하면 단순 포장·정보 전달 보수는 압박받고 권리 실사·인수·회수·필요 시각의 유동성·예외 복구가 수익 후보로 남을 수 있다.
- **C-352 / interpretation / active**: BUIDL의 다자분업, OUSG의 복수 기초상품, OIP의 모델 제공자와 발행·구현 주체 구분은 세 그룹의 자산·모델 공급, 고객 조합, 실행·사후관리와 보수 계약을 기능별로 선택할 근거다. 회사 이름 하나로 모든 책임과 수입을 묶지 않는다.
- **C-374 / hypothesis / active**: UAE 고객 AI가 동일한 투자노출·기간·위험·수취통화의 구현을 비교하면 한화는 독특한 상품과 책임 있는 유통/사후관리로 선택될 수 있지만 추가 포장 보수는 경쟁에 노출된다. 2차시장 매수와 펀드 순유입, ETC 보수와 한화 계약 보수·비용을 분리해야 경제성이 보인다.
- **C-375 / hypothesis / active**: Velocity의 확인된 기관 서비스에서 고객 AI가 현금·담보·예외·비용을 비교하면 무료 API·통합가격 경쟁으로 단위보수는 내려갈 수 있으나 완결량·회피비·신용/유동성 비용에 따라 전체 기여는 달라진다. UAE ETF 유통과는 별도 고객·계약이다.
