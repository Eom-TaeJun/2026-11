# KNX-S-006 · 이종통화송금서비스

읽은 위치: - 공식 HTML 95~119행: 중개 결제 구조·법인 대상·영업시간·무역대금·현지통화 수취·지연 유의사항.

## 자료의 핵심 내용

법인을 포함한 고객이 원화/외화를 내면 결제은행 앞으로 달러를 보내 현지통화를 지급하는 구조를 안내한다. 무역대금도 대상이며 영업시간과 현지 추가서류에 따른 입금 지연 가능성을 적는다.

## 이번 연구에 활용한 내용

- 고객의 은행계좌 접점과 실제 중개 결제 구간 분리
- 대체 결제망 비교의 종착점은 수취인의 사용 가능한 은행현금

## 해석의 한계

- 게시·갱신일 미표기. 특정 통화가 처리기간 표에 중복되고 과거 안내 가능성이 있어 국가별 가능 여부·시간은 확정하지 않는다.
- 통화 목록을 현재 실행 가능 회랑으로 사용하지 않으며 중개은행 관계·한도·가격·현지 입금 보장은 은행의 실행 견적으로 재확인 필요.

## 연결된 주장

- **C-161 / institution_statement / active**: 경남은행 이종통화송금 안내는 법인 무역대금의 달러 중개와 현지통화 수취, 현지 서류에 따른 지연 가능성을 설명한다.
- **C-168 / hypothesis / active**: 대체 결제망은 고객의 기존 은행 접점을 유지하면서 특정 구간의 최종 가용자금 도달시간 또는 총비용을 개선할 때 후속 실험할 가치가 있다.
