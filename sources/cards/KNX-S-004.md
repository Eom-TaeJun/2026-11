## 자료의 핵심 내용

KTNET이 제공하는 전자무역 서비스로 인터넷뱅킹 연계 로그인을 안내한다. 수출입·내국신용장·구매확인서·송수신문서 조회를 열거하며 가입승인과 은행 거래약정·등록을 거친다.

## 이번 연구에 활용한 내용

- 기존 전자무역·은행 접점 복원
- 별도 앱보다 가입과 실제 거래 완료까지의 마찰 검증

## 해석의 한계

- 게시일·가입자·처리량·가격·가동률 미확인.
- 데이터 연계가 가능하다는 설명은 모든 고객 ERP·K-SURE 보증·외국은행까지 실시간 연결된다는 증거가 아니다.

## 연결된 주장

- **C-158 / institution_statement / active**: 경남은행은 EDI 문서 교환과 KTNET PTB를 통한 인터넷뱅킹 연계 전자무역을 안내한다.
- **C-165 / interpretation / active**: 통합조회·전자문서·은행 연결의 존재 자체는 경남은행의 신규 차별점으로 삼기 어렵다. 고객별 미완료 단계와 운영 책임의 차이를 먼저 확인해야 한다.
- **C-166 / hypothesis / active**: 기존 fERP/PTB/EDI를 활용해 수출 건별 증빙·입금·보증·여신 신청의 상태를 연결하고 예외를 담당자에게 보내면 고객의 반복 제출과 자금공백을 줄일 수 있다.
- **C-169 / unknown / active**: 현재 공개 자료로는 경남은행 수출기업의 실제 재제출률·대사 인시·일평균 외화 잔액·활성 fERP/PTB 비중·건별 순기여와 K-SURE 전자연계의 최신 운영 상태를 확정할 수 없다.
