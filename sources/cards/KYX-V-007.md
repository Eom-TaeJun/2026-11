# KYX-V-007 · Interactive Brokers Opens AI Connectivity to Any Tool Built on the MCP Standard

## 자료의 핵심 내용

7월 발표는 MCP를 통한 계좌 연결과 AI의 지시 초안을 설명하고 고객이 IBKR 플랫폼에서 각 지시를 검토해 주문으로 바꾼다고 명시했다.

## 이번 연구에 활용한 내용

과거 승인형 AI 범위를 이후 자동거래 문서와 별도로 보존.

## 해석의 한계

7월 발표를 현재 모든 AI 기능의 한계로 일반화하지 않음. 해당 발표 자체는 자동 무승인 거래를 확인하지 않음.

## 연결된 주장

- **C-233 / institution_statement / active**: IBKR의 7월 발표·9월23일 일반 가이드는 고객 주문별 승인을 요구하지만 9월25일 표시 보충약관과 현재 안내는 별도 지정 자금에서 자동 주문하는 조건을 제시한다.
