# KYO-GEO-005 · 교보생명, 리플과 실시간 거래 ‘토큰화 국채’ 실험 나선다

## 자료의 핵심 내용

교보생명은 2025년 9월 파트너십 이후 2026년 4월 리플 인프라를 활용한 국채 거래 기술 검증을 테스트넷에서 진행한다고 밝혔다. 4월 14일 구동 현황 점검과 향후 협력을 논의했다.

## 이번 연구에 활용한 내용

- 교보생명 직접 PoC와 교보증권 간접 관찰 범위 구분
- 외국 기술기업 제휴와 국내 적용 실험 구분
- 보험기관 운용의 결제·대사 업무와 상품 판매를 구분하고 실제 현금·비용 검증을 설계.

## 해석의 한계

- 실제 테스트넷은 실자산 상용 결제와 다르다.
- 국채를 미국 국채로 특정할 근거가 없다.
- 기존 국채 거래 전체가 T+2라는 보편적 사실로 회사의 설명을 확대하지 않는다.
- 비용절감·자본효율·상용 인가·보험금 지급 연결은 미확인.
- 실거래·상용 자산 보유·구체적 USDC/USDT 이용·실현 절감은 확인하지 않았다. 현재 국채 결제 일반화를 위한 독립 근거로 사용하지 않는다.

## 연결된 주장

- **C-040 / institution_statement / active**: 교보생명은 Ripple 인프라를 활용한 국채 토큰화 거래 테스트넷 검증을 2026-04 발표했다.
- **C-219 / institution_statement / active**: 교보생명의 Ripple 국채 프로젝트는2026년4월 공식 발표상 테스트넷 기술 검증이며, NOBLX에서 생명·증권은 발표상 전략적 기관투자자다. DCG제휴는 MOU, SBI연결은 펀드와 피투자사 투자 발표로 확인된다.
- **C-223 / hypothesis / active**: 생명은 별도투자계정·ALM·자본·계열이해상충 조건을 통과할 때만 다른 외부기관과 동일한 조건으로 검토할 투자자 후보이며, 단기POD채권의 편익은 기존 적격단기자산 대비 비용·위험 후에 판단해야 한다.
- **C-225 / hypothesis / active**: 여러기관이 같은 권리·보유·배분상태를 공유해야 하는 경우에 온체인이 기존장부+AI보다 추가편익을 낼 수 있으나, 월별 정산·법적양도·은행현금이 병목이면 기존API·장부가 더 효율적일 수 있다.
