## 자료의 핵심 내용

종투사는 신청·지정과 자본·업무요건 체계다. 관련 신용공여 총합의 자기자본200% 및 기업금융/중소기업 신용을 제외한100% 한도가 있다. 계열법인 기업신용공여·계열 운용 일반사모펀드의 PBS를 제한하되 지배 해외현지법인 예외를 별도로 둔다. 단기금융업은 법360조에 따른 별도 인가가 필요하다.

## 이번 연구에 활용한 내용

- 계열 IP 협업과 계열 기업대출의 경계
- 기업신용 총한도 및 사업별 자본 사용
- 별도 단기금융업 인가와 실제 조건

## 해석의 한계

- 교보 개별 지정·인가·현재 업무범위를 증명하는 자료가 아니다.
- 계열 제한의 거래 실질·해외 예외·모든 세부 범위에 대한 법률 판단은 별도 필요하다.
- 10/2는 읽은 통합판 효력일이며 인용 조항 모두의 신규 도입일이 아니다.
- KNX-V-004와 같은 법의 다른 조문 선택 범위이며 독립된 법률로 취급하지 않는다.

## 연결된 주장

- **C-201 / fact / active**: 현행 선택 시행령상 종투사 3/4/8조 단계에는 최근 두 사업연도 결산일 연속 자본요건과 비자본 요건이 있고, 4조/8조 단계에는 직전 단계 업무의 지정일 이후 2년 계속 영위요건이 있다.
- **C-204 / fact / active**: 법77조의3은 관련 신용공여 합계의 자기자본200% 한도와 기업금융·중소기업 신용을 제외한100% 한도를 두며, 계열법인 기업신용공여와 계열 운용 일반사모펀드 PBS를 제한한다.
- **C-205 / interpretation / active**: 교보문고 자산 발굴·증권 주선/관리·생명 기관투자의 역할 제안은 계열사 직접 기업신용공여 허용을 뜻하지 않는다. 그룹 신용·인수·보증·SPV는 서비스 계약과 분리해 법적 실질·한도·위험을 심사해야 한다.
- **C-206 / fact / active**: 4조 단계 지정과 법360조 단기금융업 인가는 별개다. 단기금융 조달 한도는 자기자본200%이며 IMA를 하는 경우 IMA·단기금융 조달 합계 한도는300%다.
- **C-210 / hypothesis / active**: 반복 발행인의 권리·자료·약정·수금·사후관리 기록을 재사용하면 기존 IB에서 주선·자문·적법한 관리계약의 단위 비용을 낮추고 재발행 관계를 강화할 수 있다.
- **C-211 / interpretation / active**: 조달액·고객예탁금·IMA 수탁금·발행인 조달액·투자자 거래액은 교보 매출이 아니다. 주선/관리 보수·자기 인수 성과·기업신용/보증 기여는 각 비용·손실·자본을 반영해 별도 평가해야 한다.
- **C-227 / interpretation / active**: 그룹RWA의 주선·관리와 자기자금인수·대출·보증은 구분해야 하며, 문고직접금융·계열SPV·제3자출판사채권 경유라도 실질 계열기업신용공여·위험이전을 별도 검토해야 한다.
- **C-342 / interpretation / active**: 교보의 기존 거래·IB 수익 기반, POD 정산 절차, RCPS 결정은 서로 다른 출발 증거다. 이를 기관 고객 구성·특정 양도 가능 채권·현재 가용자본·신규 인가의 완결 확인으로 바꾸지 않는다.
- **C-344 / hypothesis / active**: 교보는 확인된 특정 원권리의 실사·구조화·기관 배분·수금·회수와 기존 고객의 거래/증거금 업무에서 대가를 확보할 수 있다. 동일 외부 상품의 포장만 추가하는 사업은 비교 경쟁으로 보수가 압박될 수 있다.
- **C-368 / hypothesis / active**: 실제 양도 가능한 확정 정산채권과 조기 자금 수요·독립 기관 수요가 존재하면, 교보의 반복 검증·발행배분·수금회수 서비스가 단발 포장보다 지속 수입을 만들 수 있다.
- **C-369 / interpretation / active**: 필요한 신규 금융 권한이 충족된 미래에도 계열 신용·보험 ALM·고객재산 분리·자본·집중은 거래별로 남는다. 생명 투자·문고 원채무 지급·증권 보수는 다른 현금과 손익이며 내부 이동은 외부 수요 증가가 아니다. 생명 자금에서 외부 P에게 지급한 Q는 외부 유출로 유지하고, 실제 동일 연결범위 안의 상환·보수만 제거한다. P의 조달 편익은 그룹 수입이 아니다.
