# ST-KY-007 · 교보문고 출판 — 사업소개

[원문](https://pub.kyobobook.co.kr/intro) · 교보문고

발행일: 미확인/동적 · 확인일: 2026-11-03

읽기 상태: **selected_sections**

읽은 위치: - 본문 사업소개: 자체 IP 발굴, 출판·독자 및 판매 데이터, 해외 번역·2차 저작물 확장, POD
- 하단 법인 명칭 확인

## 자료의 핵심 내용

교보문고는 서점 외 출판·자체 IP 발굴과 해외 번역·영상 등 확장 사업을 소개한다.

## 이번 연구에 활용한 내용

- IP 발굴·정산 데이터 협업 가설의 출발점
- 서점 유통과 개별 IP 소유·양도 가능한 청구권 분리

## 해석의 한계

- 발행일 미기재이며 현재 소개 페이지를 확인
- 개별 저작권 계약·담보가능 권리·금융상품 수익·데이터 공유권을 확인하지 않음

## 연결된 주장

- **C-132 / institution_statement / active**: 교보문고는 출판·자체IP발굴·해외번역·2차저작물 확장을 소개한다.
- **C-135 / interpretation / active**: 우선순위는 기존 거래고객의 자금·증거금 운영, 반복 IB 및 사후관리, 기관 유동성, 검증 가능한 IP, 국경간 확대 순으로 검토한다.
- **C-136 / hypothesis / active**: 이미 정산 이력이 있고 양도 가능한 IP 현금흐름은 신규 흥행위험 자산보다 초기 검증에 적합할 수 있다.
- **C-213 / institution_statement / active**: 교보문고는 자체 발굴IP의 출판·해외번역·2차저작물 확장과 주문형출판POD를 사업으로 소개한다.
- **C-220 / hypothesis / active**: 이미 발생·정산 확정된 법인 출판사의 특정월POD판매정산채권은 원권리·양도·지급자·수금을 연결하는 최초 검증 후보가 될 수 있다. 실제 금융수요·규모·기간·비용이 확인된 우선 금융상품이라는 뜻은 아니다.
- **C-226 / unknown / active**: 특정출판사P·계약채무자·기초계약·채권금액·만기·양도제한·기존담보·저자인세순위·수금통제·발행분류·투자자확약·가격·보수·생명투자약정은 확보되지 않았다.
- **C-240 / interpretation / active**: 유한한 원자산에 다수 상품을 설계해도 순자산과 독립 현금흐름이 같은 수만큼 늘지는 않는다. 별도 청구권·우선순위·손실배분·효용 변화와 동일 위험의 재포장을 구분해야 한다.
- **C-245 / interpretation / active**: IP 상품은 신탁 가능한 특정 청구권, 장래매출채권, 공동사업 투자계약증권의 법적 구조를 구분해야 한다. 토큰 형식·집합화 허용 방향만으로 동일 권리·도산절연·환금성이 생기지 않는다.
