# ST-KY-007 · 교보문고 출판 — 사업소개

발행일: 미확인/동적 · 확인일: 2026-11-03

읽기 상태: **selected_sections**

읽은 위치: - 본문 사업소개: 자체 IP 발굴, 출판·독자 및 판매 데이터, 해외 번역·2차 저작물 확장, POD
- 하단 법인 명칭 확인

## 자료의 핵심 내용

교보문고는 서점 외 출판·자체 IP 발굴과 해외 번역·영상 등 확장 사업을 소개한다.

## 이번 연구에 활용한 내용

- IP 발굴·정산 데이터 협업 가설의 출발점
- 서점 유통과 개별 IP 소유·양도 가능한 청구권 분리

## 해석의 한계

- 발행일 미기재이며 현재 소개 페이지를 확인
- 개별 저작권 계약·담보가능 권리·금융상품 수익·데이터 공유권을 확인하지 않음

## 연결된 주장

- **C-132 / institution_statement / active**: 교보문고는 출판·자체IP발굴·해외번역·2차저작물 확장을 소개한다.
- **C-135 / interpretation / active**: 우선순위는 기존 거래고객의 자금·증거금 운영, 반복 IB 및 사후관리, 기관 유동성, 검증 가능한 IP, 국경간 확대 순으로 검토한다.
- **C-136 / hypothesis / active**: 이미 정산 이력이 있고 양도 가능한 IP 현금흐름은 신규 흥행위험 자산보다 초기 검증에 적합할 수 있다.
