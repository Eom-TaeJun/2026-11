# FIN-008 · 토큰증권 관련 전자증권법·자본시장법 하위법규 개정안 입법예고 실시 ※예고기간 ‘26.10.2일 ~ 11.11일

[원문](https://www.fsc.go.kr/no010101/87838?srchEndDt=+) · 금융위원회

발행일: 2026-10-01 · 확인일: 2026-11-02

읽기 상태: **selected_sections**

읽은 위치: 보도자료 본문의 예고기간·초안 핵심 항목·시행 준비 절차. 첨부 하위법규 조문 전체는 미독.

## 자료의 핵심 내용

2026-10-02~11-11 하위법규 예고다. 발행인계좌관리기관 자기자본 40억원, 계좌관리 1명·내부통제 1명·전산 2명, 원장 참여구성, 개인 장외거래소별 연간 순매수 1억원 등은 초안이다.

## 이번 연구에 활용한 내용

STO는 법률 공포 후 세부 진입·운영 조건을 정하는 단계 허가·원장·계좌관리·유통 기능의 조건부 사업 기회

## 해석의 한계

최종 규칙이 아니며 모법의 10억원 위임 하한을 대체하는 확정 법규가 아니다. 분산원장 이용의 직접 대가 제한을 모든 서비스 수수료 금지로 확대하지 않는다.

## 연결된 주장

- **C-001 / fact / active**: 11/2 기준 토큰증권 하위법규는 10/2~11/11 예고 단계다. 전자증권법 제21318호와 자본시장법 제21324호 제166조의 예정 시행은 2027-02-04이며 제21324호 전체가 그날 처음 시행되는 것은 아니다.
- **C-008 / hypothesis / active**: 발행 이후 권리·명부·분배·공시·환매를 연결하는 서비스가 반복 업무의 보수 기회가 될 수 있다.
- **C-030 / hypothesis / active**: 제도 시행과 개별 인가가 진행돼도 기존 계좌·수탁과의 이중 운영이 남아 B2B 권리관리·대사·현금 연결이 먼저 필요해질 수 있다.
- **C-054 / hypothesis / active**: 교보증권의 해외 자산·투자자 연결이 실제 발행·판매·관리 계약으로 확대된다면 반복 서비스 보수 후보가 될 수 있다.
- **C-057 / fact / active**: 한국 / 전자증권법 제21318호: 개정문·부칙을 확인했다. 발행인계좌관리기관 등록과 분산원장 전자등록의 법률 근거가 마련된다.
- **C-059 / fact / active**: 한국 / 자본시장법 제21324호 제166조 장외거래: 제166조는 공포 후 1년 경과 시행이다. 인가업무 단위·투자금액·결제방법의 구체화가 하위법령에 남는다.
- **C-060 / fact / active**: 한국 / 토큰증권 하위법규 예고: 의견 마감 2026-11-11. 모법 자기자본 위임 하한은 10억원; 예고안 구체 금액은 40억원이다.
- **C-098 / hypothesis / active**: 규칙 적용과 개별 허용이 진행되면 기존 계좌·수탁·현금 경로를 연결하는 업무가 먼저 필요해질 수 있다.
- **C-139 / fact / active**: 전자증권법21318 및 자본시장법21324의166조 관련 미래 시행은2027/2/4이며 하위법규·개별 권한·현금 레일은 별도 관문이다.
