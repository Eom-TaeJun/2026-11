## 자료의 핵심 내용

탐색·거래·조정 비용 변화에서 기업 경계와 통제된 자율성을 질문하는 교육자료다.

## 연결된 주장

- **C-103 / interpretation / active**: AI와 토큰화가 비교·전달 비용을 낮춰도 자본·신뢰 가능한 권리·유동성·계약집행의 희소성이 사라지지는 않으며 보수와 책임의 제공자가 재편될 수 있다.
- **C-113 / hypothesis / active**: AI가 공급자를 쉽게 비교·교체하면 표준 처리 보수가 낮아질 수 있으나 고객 접속·데이터·자본·규모의 이익이 크면 대형 플랫폼 집중이 강화될 수도 있다.
- **C-116 / interpretation / active**: 투자 우선순위는 반복 고객 업무, 실제 통제 가능한 희소 자원, AI가 검증할 계약·비용, 돈·손실의 귀속, 경쟁 후 수익과 다음 관측으로 정해야 한다.
- **C-192 / hypothesis / active**: 거래자료 표준화와 AI 비교가 확산되면 지역 관계금융의 정보 우위 일부는 줄어들고, 현장 검증·분쟁 해결·스트레스 때 확약한도를 공급하는 능력이 남는 차별성이 될 수 있다.
- **C-193 / hypothesis / active**: 권한과 레일이 성립한 미래에는 은행이 모든 고객자산을 자기 예금으로 보유하지 않아도 실행·현금화·신용·복구의 공급자로 수익을 얻을 수 있다.
- **C-196 / hypothesis / active**: 제도·인가·권리·현금·고객 위임이 모두 성립해도 고객별 총편익과 은행의 증분 기여가 동시에 양수인 업무만 확대하는 경로가 합리적이다. 거래량·수탁잔액 증가만으로 사업성을 증명할 수 없다.
- **C-243 / hypothesis / active**: 외부 AI가 상품과 견적을 비교하는 미래에 교보가 정확한 권리·현금 조건과 실제 실행·사후관리 상태를 제공하면 자체 앱 밖에서도 고객 업무를 확보할 수 있다.
- **C-436 / interpretation / active**: Coase 관점에서 Agent의 탐색·보고·조정비 감소와 작은 조직의 반복 분석 가능성을 제시한다. 기업이 커질지 작아질지는 토론 질문으로 열어 둔다. 이번 분석: 외부 공급자 탐색·계약·검증비와 기업 내부 조정비가 모두 변할 수 있으므로 AI라는 이유만으로 작은 기업 우위를 확정할 수 없다. 상대비용 비교는 이번 분석자의 구체화다.
- **C-437 / interpretation / active**: Hermes 강의는 증거·시점·재현성을 금융 분석의 최소 계약으로 두고, 먼저 한 Agent의 정확한 완료를 확인한 뒤 분업하도록 권한다. 위임은 비교우위 이익과 목표 전달·증거 손실·책임 문제를 함께 만든다. 이번 분석: 전문화/병렬화 이익에서 목표 전달·재검증·오류 복구 비용을 차감해야 하며, 입력 고정·출력 형식·검증 담당이 필요하다.
- **C-442 / hypothesis / active**: 필요한 권리·인가·동의·다기관 상태 공유가 성립한 2027년 이후, 확인 가능한 원청 지급채권이 있지만 작은 건별 확인·관리 고정비 때문에 해당 조달을 이용하지 못했던 협력기업에게 반복 운전자금 서비스가 새로 성립할 수 있다. 기존 fERP+AI로 현 고객의 현금·여신관계를 개선하는 경로와 병행해 소규모 신규 고객 검증을 우선한다. 이번 조건 검토: 초기입장의 새 협력기업 수요를 유지하고, 시간·온체인·경쟁별로 직접 수행·기존 레일·제휴 선택을 새로 구체화
- **C-443 / hypothesis / active**: 양도·수금 가능한 확정 정산채권이 있는 외부 콘텐츠 사업자와 적격 투자자가 있고 발행·관리 고정비가 주된 비거래 이유라면, 반복 소액 채권의 모듈형 발행·관리 계약이 새 고객 시장을 열 수 있다. 기존 IB 발행/사후관리 자동화와 병행하고 원권리 관리·투자자 목적별 구성에 별도 보수가 남을 가능성을 우선 검증한다. 이번 조건 검토: 상품 조합 자체의 별도 보수보다 고객이 값을 내는 수금/권리 관리에 집중하고 단순 팩토링을 우선 비교
- **C-444 / hypothesis / active**: 현지 인가·약관·동의·IDR 지급·판매 권한이 충족되고 감당 가능한 위험보험료가 존재한다면, 설명·명부·납입·청구 관리비 때문에 첫 적합한 보장을 제공하지 못했던 소규모 고용주에게 단체 정액보장과 관리 서비스가 성립할 수 있다. 기존 국내 보험·GA 유지/청구 개선과 병행해 현지 고용주의 실제 지급 의사를 검증한다. 이번 조건 검토: 초기에 고정한 고용주·인수 가능 직원집단과 IDR 경로를 유지. 동등 성과 조건에서는 기존 IDR+AI를 우선하고 별도 AI 관리료·직접 플랫폼은 조건부 포기
