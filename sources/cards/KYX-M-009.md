# KYX-M-009 · 정산/판매내역 조회방법 안내

[원문](https://store.kyobobook.co.kr/pod/notice/1001541) · 교보문고

발행일: 2023-11-10 · 확인일: 2026-11-03

읽기 상태: **selected_sections**

읽은 위치: - POD 판매내역·정산내역·장부내역 세 메뉴 설명, 채널·집계시차·지급조건, 웹33~112행

## 자료의 핵심 내용

공개 안내는 B2C/B2B/OFF 판매·정산·지급장부를 분리한다. 주문 즉시 판매내역이 갱신되지 않으며 B2C 배송완료 후 최대10영업일, B2B/OFF 마감후D+2, 정산내역D+3을 안내한다. 출판사는 계산서 발행 또는 승인 조건이 있다.

## 이번 연구에 활용한 내용

- 판매 이벤트와 확정 정산·실제 입금의 구별
- AI 입력 데이터 신선도·은행대조·계산서 확인 설계

## 해석의 한계

- 표시 게시일2023-11-10이나 본문에2025년 예시가 있어 수정일은 미확인
- 안내 시차를 해당 거래의 확정 SLA로 쓰지 않음
- 파트너 계정 내부 원장은 조회하지 않음

## 연결된 주장

- **C-214 / institution_statement / active**: 교보문고 POD 공개 FAQ는 법인 출판사의 전자계약, 콘텐츠 공급·주문 후 제작, 파트너 정산 및 계산서 절차와 정가20% 정산을 안내한다. 공개 판매·정산·지급장부 안내는 각 단계와 집계시차를 구분한다.
- **C-220 / hypothesis / active**: 이미 발생·정산 확정된 법인 출판사의 특정월POD판매정산채권은 원권리·양도·지급자·수금을 연결하는 최초 검증 후보가 될 수 있다. 실제 금융수요·규모·기간·비용이 확인된 우선 금융상품이라는 뜻은 아니다.
- **C-221 / hypothesis / active**: 필요한 법적 권한·유효한 양도·수금통제·외부기관 수요가 성립하면, 증권사는 반복 채권 검증·구조화·주선·수금대조·분쟁관리 업무에서 계약상 보수를 얻을 수 있다.
- **C-224 / hypothesis / active**: AI가 상품 비교·조합을 늘려도 한정된 원권리의 현금은 늘지 않는다. 권리별 중복 양도·담보·배분, 실제수금·정정·회수의 지속 검증이 관리 서비스의 가치 후보가 된다.
- **C-225 / hypothesis / active**: 여러기관이 같은 권리·보유·배분상태를 공유해야 하는 경우에 온체인이 기존장부+AI보다 추가편익을 낼 수 있으나, 월별 정산·법적양도·은행현금이 병목이면 기존API·장부가 더 효율적일 수 있다.
- **C-226 / unknown / active**: 특정출판사P·계약채무자·기초계약·채권금액·만기·양도제한·기존담보·저자인세순위·수금통제·발행분류·투자자확약·가격·보수·생명투자약정은 확보되지 않았다.
