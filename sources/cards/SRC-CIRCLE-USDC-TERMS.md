## 자료의 핵심 내용

비 EEA USDC 약관은 보유자와 적격 Circle Mint 고객을 구분하고 직접 상환을 자격·법·약관 조건에 둔다. USDC 자체는 보유자에게 준비자산 이자를 지급하는 상품으로 설계되지 않았다.

## 이번 연구에 활용한 내용

- 지급 스테이블코인 보유와 은행예금·수익형 펀드 지분의 권리를 구분한다.
- 토큰 수취와 발행자 상환, 은행 현금 도착을 별도 단계로 조사할 근거로 사용한다.
- 토큰 보유·전송·직접 상환·은행 현금을 별도 상태로 평가
- 수익형 자산과 지급 잔액, 발행자 준비금 수익 분리

## 해석의 한계

- 약관의 선택 부분을 읽었으며 개정 전후 모든 조항을 비교하지 않았다.
- 개별 한국 기관의 가입·상환 적격성, 실제 상환 소요시간·수수료·현재 거래 가능성을 확인하지 않았다.
- 약관 전체 개정 이력을 비교하지 않았다.
- 거래별 현재 수수료·은행 입금시간·한화 고객 자격·제휴는 확인되지 않는다.
- EEA 고객에는 별도 법적 문서가 적용될 수 있다.

## 연결된 주장

- **C-009 / hypothesis / active**: 결제·환매·은행현금과 FX를 연결하는 기업 자금관리 서비스가 고객 가치를 만들 수 있다.
- **C-130 / unknown / active**: 교보증권의 직접 Circle Mint 상환·고객 USDC 레일 및 USDT 발행/유통사 직접 계약은 확인되지 않았다.
- **C-134 / fact / active**: Circle 비EEA 약관은 직접 상환 자격·Mint등록 조건과 USDC 보유자의 준비자산 이자수익 권리 부재를 구분한다.
- **C-148 / fact / active**: USDC와 USDT는 보유·이전과 발행자 직접 상환 자격이 같지 않다. 은행 현금 수취와 수익·비용은 추가 계약·경로에 달린다.
- **C-151 / hypothesis / active**: AI가 상품을 비교할수록 공시·가격·자격·환매·실행·복구 정보의 품질이 유통 경쟁력이 될 수 있지만 상품 소개 보수는 압박받을 수 있다.
- **C-153 / interpretation / active**: 보험 ALM의 온체인 시험은 동일 통화·권리·만기·지급의무에서 최종 현금·총비용·스트레스 자금 수요를 비교해야 한다.
- **C-174 / interpretation / active**: 스테이블코인이나 펀드 지분을 수취했다는 사실만으로 외화 은행현금 수취 또는 원채무 이행을 확정할 수 없다.
- **C-180 / hypothesis / active**: 고객의 유휴 예금을 줄이는 자금관리 서비스는 고객 편익을 높이면서 경남은행의 조달 기여를 줄일 수 있다. 서비스·FX·대출·예금의 기여와 파트너 비용을 동일 기준의 순증감으로 계산하여 예금 잠식·조달비·내부 FTP를 중복 반영하지 않아야 한다.
- **C-199 / interpretation / active**: 동일한 명목 자산가치를 보유해도 필요한 통화의 은행현금 전환이 늦으면 지급기일의 자금 부족이 발생한다.
- **C-236 / interpretation / active**: USDC·USDT 직접 상환은 발행자 자격·계약·규모·은행시간을 필요로 하며, 보유자가 지급한 전환수수료와 발행자의 준비금수익은 증권사의 수익으로 자동 귀속되지 않는다.
