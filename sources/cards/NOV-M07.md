- **C-105 / institution_statement / active**: IMF GFSR 제3장 Box 3.2는 즉시에 가까운 양자 결제가 상계 기회를 줄여 유동성·대차대조표 비용을 늘릴 수 있고 배치·중앙청산 설계가 중요하다고 분석한다.
- **C-112 / interpretation / active**: 기술적 토큰 생성 비용과 법적 금융상품의 실사·권리 설정·공시·수탁·세금·유통·사후 관리 비용은 다른 비용이다.
- **C-113 / hypothesis / active**: AI가 공급자를 쉽게 비교·교체하면 표준 처리 보수가 낮아질 수 있으나 고객 접속·데이터·자본·규모의 이익이 크면 대형 플랫폼 집중이 강화될 수도 있다.
- **C-114 / hypothesis / active**: 법과 레일이 정착해도 작은 수요·비정형 권리의 검증비·유동성 비용 때문에 일부 반복 업무에서만 토큰화가 채택되고 기존 방식과 공존할 수 있다.
- **C-116 / interpretation / active**: 투자 우선순위는 반복 고객 업무, 실제 통제 가능한 희소 자원, AI가 검증할 계약·비용, 돈·손실의 귀속, 경쟁 후 수익과 다음 관측으로 정해야 한다.
- **C-190 / interpretation / active**: 고객의 외부 펀드·코인 잔액은 은행 예금이나 은행의 조달자산이 아니며 발행자 준비자산 수익은 고객 또는 경남은행의 수익과 다르다. 토큰 잔액·환매청구·실제 지급 가능 현금은 별도 상태다.
- **C-191 / hypothesis / active**: 고객이 잉여금을 예금 밖에서 효율적으로 운용할수록 은행의 저원가 조달과 대출 수요 일부는 줄 수 있다. 경남은행은 필요한 지급시각·유동성·예외 복구를 유료로 완결할 때 새 수익으로 이를 보전할 수 있다.
- **C-194 / hypothesis / active**: 24/7 전송이 가능해져도 환매·FX·은행 입금 시간과 총액 사전조달 때문에 지급 확실성에 대한 수요는 남을 수 있다. 가격에 책임과 한도 비용이 반영되는 유동성 약정은 한 수익 후보다.
- **C-196 / hypothesis / active**: 제도·인가·권리·현금·고객 위임이 모두 성립해도 고객별 총편익과 은행의 증분 기여가 동시에 양수인 업무만 확대하는 경로가 합리적이다. 거래량·수탁잔액 증가만으로 사업성을 증명할 수 없다.
- **C-199 / interpretation / active**: 동일한 명목 자산가치를 보유해도 필요한 통화의 은행현금 전환이 늦으면 지급기일의 자금 부족이 발생한다.

- **C-355 / interpretation / active**: 같은 기초자산의 ETF·발행상품·포트폴리오·담보 잔액을 더해 신규 독립 자산이나 외부 순유입으로 계산할 수 없다.
- **C-356 / hypothesis / active**: 상품·권리·실효비용을 고객 AI가 비교하고 적법하게 위임할 수 있다면 표준 구현·설명 보수는 경쟁 압력을 받고 실사·인수·현금·복구 기능의 가격이 더 중요해질 수 있다.
- **C-358 / interpretation / active**: 기술이 줄인 단위비용만으로 플랫폼이나 금융그룹 이익 증가를 결론낼 수 없다. 유료 고객·평균 잔액·실효가격·비용·기존사업 잠식·자본을 같은 기간으로 비교해야 한다.
- **C-376 / hypothesis / active**: 규제·법인권한·위임·온체인 현금경로가 성립해도 고객에게 유리한 조합은 한화 내부 완결망과 같지 않을 수 있다. 표준화·총액결제·경쟁 가격전가가 그룹의 유통·조달·선자금·위험 기여를 바꾸므로 기존+AI와 외부 조합을 계속 비교해야 한다.
- **C-379 / interpretation / active**: 기존 무AI 대비 변화와 기존+AI 대비 온체인의 추가 변화를 나눠야 예금 이동·보수 감소·운영 절감을 모두 온체인 효과로 오인하지 않는다.
- **C-380 / interpretation / active**: 새 업무의 외부 수입에서 그 업무 비용·추가 고정비·기존 업무 순기여 감소를 차감하면 잠식을 포함한 증분 기여를 볼 수 있다. 회사 전체 순증감으로 이미 계산했으면 잠식을 다시 빼지 않으며 계열 내부 보수를 외부 매출로 중복 합산하지 않는다.
- **C-381 / hypothesis / active**: 규제·온체인 연결이 정상이어도 여러 고객 AI가 같은 때 환매·동일 통화 지급을 요청하면 재고·조달·신용·상계 조건에 따라 가격과 제공량이 바뀌고, 지급 버퍼·회수·보험금 현금·예외 처리의 가치가 커질 수 있다.
