# ST-KN-005 · Cyber Branch 제공서비스

발행일: 미확인/동적 · 확인일: 2026-11-03

읽기 상태: **selected_sections**

읽은 위치: - 공식 서비스 목록 1315~1371행: 통합자금관리·B2B·이체·외화/수출입·기초정보·ERP 표시
- 이번 재확인: 공개 HTTP HTML의 Cyber Branch 제공서비스 표, 외화/수출입·기초정보 및 별표 ERP연계 주석. 기존 ID 유지. 웹 열기 실패 후 직접 HTTP 조회 성공.

## 자료의 핵심 내용

통합자금·B2B·이체·외화송금·수출입과 관리자의 결재단계 설정을 안내한다. ERP 연계는 표에서 별표한 항목에 한정해 표시한다.

## 이번 연구에 활용한 내용

- 기존 은행 API·ERP 기능의 경쟁 기준선
- 기능 보유만으로 경남은행의 차별성이 성립하지 않음을 설명
- 기업 승인·권한 및 기존 자금관리의 경쟁 기준
- 웹 화면 기능과 ERP 연결 가능 기능 구분

## 해석의 한계

- 공개 기능 안내이며 활성 이용·효과·개별 계약·가격이나 AI/온체인 구현의 증거가 아니다.
- 시장 전체 우위·비교 성능을 측정하지 않았다.
- 해외 건별송금·수입신용장 등을 포함한 모든 기능이 ERP 연계 가능하다고 일반화할 수 없다.
- 실사용·가격·가동률·AI 또는 온체인 성능 비교를 확인한 자료가 아니다.

## 연결된 주장

- **C-122 / hypothesis / active**: AI 기반 비교·자금배분이 보편화되면 고객의 유휴 잔액과 은행 전환비용이 줄어 지역은행의 조달·유통 마진이 압박받을 수 있다.
- **C-124 / interpretation / active**: 경남은행의 첫 비교는 같은 고객 업무의 기존+AI와 허용된 온체인+AI를 대상으로 최종 은행현금·대사·권한·총비용을 같게 맞추어야 한다.
- **C-164 / institution_statement / active**: KB Cyber Branch는 자금관리·외환/수출입과 관리자 결재단계 설정을 안내하고 ERP 가능 항목을 별표로 구분한다.
- **C-165 / interpretation / active**: 통합조회·전자문서·은행 연결의 존재 자체는 경남은행의 신규 차별점으로 삼기 어렵다. 고객별 미완료 단계와 운영 책임의 차이를 먼저 확인해야 한다.
- **C-168 / hypothesis / active**: 대체 결제망은 고객의 기존 은행 접점을 유지하면서 특정 구간의 최종 가용자금 도달시간 또는 총비용을 개선할 때 후속 실험할 가치가 있다.
