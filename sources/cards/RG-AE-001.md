# RG-AE-001 · ADGM FSRA finalises regulatory framework for Regulated Activities involving Fiat-Referenced Tokens

[원문](https://www.adgm.com/media/announcements/adgm-fsra-finalises-regulatory-framework-for-regulated-activities-involving-fiat-referenced-tokens) · ADGM FSRA

발행일: 2025-10-31 · 확인일: 2026-11-03

읽기 상태: **selected_sections**

읽은 위치: - FSRA 보도자료 웹행55–70

## 자료의 핵심 내용

2025-10-31 확정한 FRT 관련 규제활동 개정 체계는 2026-01-01 효력이다. 수용 FRT·고객 FRT 통제와 발행자 요건을 다룬다.

## 이번 연구에 활용한 내용

- ADGM FRT 개정 단계와 시행일
- 현재 일반체계의 효력과 개별 회사 허가를 분리한다.

## 해석의 한계

- 연결된 규칙 개정문 서버는 403이어서 모든 조문을 직접 읽지는 못했다. 공식 규제기관 확정 발표에 한정한다.
- 이번에는 연결된 최종 규칙 전체를 다시 읽지 않았다. 한화의 FSP를 증명하지 않는다.

## 연결된 주장

- **C-083 / fact / active**: UAE / Abu Dhabi Global Market (ADGM) / Digital Securities / Fiat-Referenced Tokens / Financial Services Permission: 2025년 확정 FRT 개정은 2026-01-01 시행됐다. 증권 성격 토큰은 증권 규율을 따르며 규제활동에는 FSP가 필요하다. IPA·조건 충족·FSP 및 인정 FRT는 별도 확인 단계다.
- **C-146 / interpretation / active**: 한화생명–ADIO와 한화자산운용–ADGM·하나금융 협약의 당사자·범위는 다르며 생명 협약에 ADGM 관할을 자동 적용할 수 없다.
- **C-255 / fact / active**: ADGM FRT 체계는2026-01-01 효력이지만 특정 회사의 개별 FSP·상품·고객 범위는 별도다. 증권인 토큰은 증권 규율을 받는다.
