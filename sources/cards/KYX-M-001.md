## 자료의 핵심 내용

법인·공동대표 출판사는 전자계약 후 콘텐츠를 공급하며 주문 후 제작되고 파트너시스템에서 정산한다. 출판사 안내에는 정가의 20%와 계산서 발행 시 익월 25일 지급이 제시된다. 개인작가는 1만원 이상 발생 시 익월 20일, 휴일이면 전 영업일이며 원천징수 후 등록 계좌로 받는다고 안내한다.

## 이번 연구에 활용한 내용

- 권리자가 받을 청구권과 플랫폼의 정산 업무가 존재한다는 운영 근거
- 개인작가와 출판사 계약·일정을 분리
- 공개 안내의 지급일 불일치 식별

## 해석의 한계

- 특정 당사자가 체결한 계약·정산 원장·채권 양도 조항·실제 입금은 미확인
- 익월25일 안내와 연결된 2022년 공지의 20일경 안내가 달라 출판사 개별 채권 지급일은 null
- 입금자 표시 '교보전자책'만으로 계약 채무자 법인을 확정하지 않음
- 계정 로그인·비공개 판매 데이터 조회는 하지 않음

## 연결된 주장

- **C-214 / institution_statement / active**: 교보문고 POD 공개 FAQ는 법인 출판사의 전자계약, 콘텐츠 공급·주문 후 제작, 파트너 정산 및 계산서 절차와 정가20% 정산을 안내한다. 공개 판매·정산·지급장부 안내는 각 단계와 집계시차를 구분한다.
- **C-215 / unknown / active**: 출판사 지급일은 현재 FAQ의 익월25일과 연결된 공식 지급공지의20일경 설명이 달라, 특정 계약과 채무자 확인 전 확정하지 않는다. 개인작가의 별도 조건과 과거2018년 적용 약관도 출판사 최신 거래에 자동 적용하지 않는다.
- **C-220 / hypothesis / active**: 이미 발생·정산 확정된 법인 출판사의 특정월POD판매정산채권은 원권리·양도·지급자·수금을 연결하는 최초 검증 후보가 될 수 있다. 실제 금융수요·규모·기간·비용이 확인된 우선 금융상품이라는 뜻은 아니다.
- **C-226 / unknown / active**: 특정출판사P·계약채무자·기초계약·채권금액·만기·양도제한·기존담보·저자인세순위·수금통제·발행분류·투자자확약·가격·보수·생명투자약정은 확보되지 않았다.
- **C-297 / interpretation / active**: 국가별 사회적·산업적 수요는 접근가능 고객과 다르다. 국가의 지급/투자/보장 문제를 특정 고객·법인·통화·기간·지급자와 기존 대안으로 좁힌 뒤 그룹 자원을 배치해야 한다.
- **C-342 / interpretation / active**: 교보의 기존 거래·IB 수익 기반, POD 정산 절차, RCPS 결정은 서로 다른 출발 증거다. 이를 기관 고객 구성·특정 양도 가능 채권·현재 가용자본·신규 인가의 완결 확인으로 바꾸지 않는다.
- **C-344 / hypothesis / active**: 교보는 확인된 특정 원권리의 실사·구조화·기관 배분·수금·회수와 기존 고객의 거래/증거금 업무에서 대가를 확보할 수 있다. 동일 외부 상품의 포장만 추가하는 사업은 비교 경쟁으로 보수가 압박될 수 있다.
- **C-348 / interpretation / active**: 같은 원천 채권·펀드·담보의 포장을 늘려도 독립된 기초 현금흐름은 자동으로 증가하지 않는다. 맞춤 효용·위험배분과 총청구·레버리지·집중·기한 불일치를 분리해 평가해야 한다.
- **C-351 / unknown / active**: 세 그룹의 제안별 실제 신규 계약·고객 수·계약가격·예산·순이익·ROI와 특정 글로벌 상품의 고객별 이용 적격성은 이번 연결 메모에서 확인되지 않았다.
