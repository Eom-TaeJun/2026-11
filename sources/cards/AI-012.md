## 자료의 핵심 내용

BM25·벡터·재정렬을 결합하는 로컬 문서 검색 도구다. 5월 v2.5.3은 문서 ID·경로·행 번호 출력을 강화했고 최신 공개 릴리스 v2.8.3은 로컬 설정 신뢰·경로 제한 등을 수정했다. 현재 기본 브랜치 기능과 릴리스에 포함된 기능은 구분해야 한다.

## 이번 연구에 활용한 내용

- 근거 원문·정리된 위키에서 정확한 명칭과 의미 검색
- 판정: 우선 비교 시험 — 한국어 금융 용어와 날짜·법인명 검색을 기존 검색과 비교

## 해석의 한계

- 로컬 임베딩·재정렬 모델과 인덱스 갱신
- 문서 ID·행 번호를 원본 버전 해시에 추가 연결
- 기존 WeKnora 검색이 충분하면 별도 색인 불필요
- 단순 전체 읽기/키워드 검색보다 관련 원문 찾기 개선 가능
- 실제 금융 자료 성능·비용 시험과 설치는 수행하지 않았다.

## 연결된 주장

- **C-015 / interpretation / active**: 출처 ID·읽은 범위·파생 위키·정정 이력·독립 검증을 먼저 도입하고 검색·그래프 도구는 실제 실패 과제로 비교한다.
