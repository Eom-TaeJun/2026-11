## 자료의 핵심 내용

공식 페이지는 Ethereum·BNB Chain·Solana 사용 가능을 표시한다. BlackRock의 모델 제공과 Ondo 발행 증권의 권리·판매 제한을 분리한다.

## 이번 연구에 활용한 내용

- 9월 Solana 계획 표시를 11월 공식 사용 가능 표시로 갱신
- 브랜드·모델 공급을 펀드 직접 소유권이나 판매 자격으로 바꾸지 않음

## 해석의 한계

- 체인별 계약·유동성·모든 상품 지원을 온체인 검증하지 않았다.
- 광범위한 홍보 문구는 적격성·관할·직접 투자 조건에 종속된다.
- 현재 페이지 확인이며 각 기능의 최초 개시일·실제 거래·매출은 확인하지 않았다.

## 연결된 주장

- **C-307 / institution_statement / active**: Ondo 현재 고지는 BlackRock 모델 공급, Ondo 구현·발행, 토큰 투자자의 권리를 분리한다. BlackRock 브랜드는 해당 토큰에 대한 BlackRock의 투자자 자문 관계나 기초 ETF 직접 청구권을 뜻하지 않는다.
- **C-313 / institution_statement / active**: 9월 강의의 Solana 예정 표시는 11월 4일 공식 제품 페이지의 사용 가능 표시로 갱신할 필요가 있다.
- **C-314 / interpretation / active**: 2026-09-24 출시 발표와 09-28 강의가 다룬 첫 세 상품의 고정 구성·정기 리밸런싱은 당시 로드맵의 동적 구성·파생상품·중첩 전략과 구분해야 한다. 현재 공식 제품 페이지의 7개 라인업을 첫 세 상품으로 축소하지 않는다.
