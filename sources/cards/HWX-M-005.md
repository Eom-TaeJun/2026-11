## 자료의 핵심 내용

BPJS의 Mobile JKN 안내에는 가입·보험료 납부용 가상계좌와 가족 가입 상태 조회 기능이 있다. 민간 보험 설계 전 기존 공적 보장의 상태를 확인하고, 새 앱의 중복 기능을 피해야 하는 운영상 근거다.

## 이번 연구에 활용한 내용

- JKN 미가입·비활성·보장 부족을 구분할 고객 여정
- 이미 존재하는 관리 기능 대비 추가 가치 검증

## 해석의 한계

- 게시일 없음. 전체 JKN 법·급부·보험료 규정을 확인한 자료가 아니다.
- 외부 회사 API 접근권·건강정보 공유 동의를 부여하는 문서가 아니다.
- 참가자 수·충분 보장률·민간보험 수요를 제시하는 자료가 아니다.

## 연결된 주장

- **C-278 / hypothesis / active**: 기존 방카 고객의 보장 확인·납입 유지·청구 안내를 개선하면 신규 판매 확대보다 먼저 반복 지원비용과 고객 오류를 줄일 수 있다.
- **C-280 / hypothesis / active**: 고용주의 직원 보장·자격 변경·청구 관리는 LGI 보험과 연결할 수 있는 별도 후보다.
