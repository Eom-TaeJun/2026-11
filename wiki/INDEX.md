- [결제·대사·상호운용성](T-SETTLEMENT.md): 기존 계좌와 새 원장의 연결에서 시간·선예치·실패·복구 비용이 어떻게 바뀌는가?
- [담보·자본·유동성위험](T-COLLATERAL.md): 담보권·적격성·헤어컷·마진과 현금 공급 약정은 어떻게 정해지는가?

- [한국과 해외 제도·시행 단계](T-REGULATION.md): 제안·확정·효력·개별 인가와 국내 적용 조건을 어디까지 확인했는가?
- [수탁·준법·정보·운영 복구](T-OPERATIONS.md): 누가 자산·권리·현금을 대사하고 실패·정정·고객 피해를 책임지는가?
- [은행 조달·고객 자금관리](T-FUNDING.md): 고객의 지급·투자 잔액 변화가 개별 은행 조달비와 반복 수익에 어떤 조건부 영향을 주는가?
- [AI 연구 하네스·검색·지식 갱신](T-AI.md): 어떤 방법이 근거 누락·중복·정정 비용을 줄이며 기준선 대비 효과를 어떻게 검증하는가?
- [증권·은행·보험과 후보 기업](T-COMPANIES.md): 환경 변화가 어떤 업무를 만들며 후보 기업은 실제 어떤 역량과 자원을 배치했는가?
- [금리·성장·물가·거시 금융여건](T-MACRO.md): 실적·전망·정책결정을 구분할 때 조달비·현금 수익·신용·외환 위험이 사업 조건을 어떻게 바꾸는가?
- [기업 연결 국가·관할·파트너](T-GEOGRAPHY.md): 어떤 법인·자본·고객·거래가 국가를 연결하며 직접 영업·간접 관계·목표를 어떻게 구분하는가?

- [AI가 선택·위임·실행하는 금융서비스](T-AGENT-FINANCE.md): 고객 AI가 금융상품·공급자를 비교하고 업무를 위임할 때 계약·권한·현금·책임·보수의 배분은 어떻게 바뀌는가?
