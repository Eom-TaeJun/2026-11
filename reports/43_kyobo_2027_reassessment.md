## 3. 경제 원리로 보면 어디에 경쟁이 생기는가

**정보 탐색비와 금융 책임의 비용은 다르게 움직인다.** 고객 AI가 보장·투자 목적, 비용, 해지·환매 조건을 쉽게 비교하면 정보 설명과 단순 재포장의 보수는 압박받는다. 그러나 보험자의 장기 위험공동부담, 발행인의 실제 현금흐름 검증, 손실 발생 후 회수·정정·지급 책임은 자동 소멸하지 않는다. 이 기능도 경쟁자가 더 싸고 정확하게 제공하면 보수는 낮아진다. 따라서 ‘신뢰가 필요하다’는 설명만으로 교보의 높은 보수를 정당화할 수 없다.

**표준화는 비정형 자산의 공급을 늘리면서 검증 독점력도 낮춘다.** 첫 계약의 실사 틀·보고·정산 자료를 재사용하면 작은 발행인이 자본시장에 접근할 문턱이 내려갈 수 있다. 동시에 같은 검증 결과가 다른 중개사·투자자에게도 열리면, 교보가 처음 자료를 만들었다는 이유만으로 높은 발행 보수를 계속 받을 수 없다. 유지될 후보는 반복적인 원천 데이터 확인, 실제 수금 통제, 투자자에게 적합한 배포, 문제가 났을 때의 집행·관리 계약이다. 원천 검증과 관리까지 경쟁자가 같은 품질로 제공하면 외부 서비스를 구매하거나 좁은 전문 업무로 축소한다.

**대형사는 이미 자기자본·고객·기존 인프라를 이용해 새 레일을 흡수할 수 있다.** 미래에셋의 디지털 채권 발행에서 HSBC는 주관사, Orion은 기술 플랫폼, CMU는 발행·결제 연결의 기반으로 제시됐다. 이 사례는 미래에셋의 조달 실행 경험을 확인하며, 해당 조달액을 디지털 서비스 매출이나 외부 고객 확대 성과로 바꾸지 않는다. 교보의 경쟁 상대는 새로운 토큰 스타트업뿐 아니라 기존 업무에 디지털 방식을 붙이는 글로벌·국내 금융사다. [거래 자문사 원문: R27-K-009](https://www.linklaters.com/en/about-us/news-and-deals/deals/2026/march/linklaters-advises-on-koreas-first-digitally-native-bond-issuance)

그들이 기관 연결·보고 서비스를 낮은 가격에 묶으면 교보는 범용 발행 플랫폼 전체를 소유할 유인이 줄어든다. 대신 기존 발행인과 특정 투자자의 목적을 아는 전문 구간에서 계약을 확보하고, 표준 기술은 구매하는 편이 유리할 수 있다. 반대로 자체 규모·반복 업무가 충분해 외부 가격보다 총원가가 낮아지면 내부화가 합리적이다. 어느 방향도 기술의 이름만으로 결정하지 않는다.

## 4. 미래전략 관점의 세 우선 업무

### 1. 생명: 고객 AI가 읽고 실제로 완료할 수 있는 장기 계약관리

지금 보험료가 저렴한 상품을 보여주는 일에 그치지 않고, 현재 보장의 목적·변경 조건·해지 손실·갱신·청구 진행·지급 결과를 일관되게 제공한다. 고객이 원할 때 FP가 복잡한 상황을 설명하고, 간단한 조회·증빙·일정·상태 확인은 디지털 절차로 끝나도록 설계한다. 회사도 FP를 가입 이후 유지·보장 점검·지급까지 이어지는 역할로 설명한다. [FP 역할: HWX-V-006](https://news.kyobo.com/교보생명-fp-고객보장-완주/)

예를 들어 소득이 일시적으로 줄어든 고객의 AI가 해지, 납입 방식 변경, 계약대출 등 **해당 계약에서 실제 가능한 선택**의 총비용과 보장 영향을 비교한다고 가정한다. 교보는 무조건 해지를 막기보다 적합한 선택과 실행 결과를 제공해야 한다. 고객이 외부 저축상품으로 일부 돈을 옮겨도 필요한 위험보장은 남을 수 있다. 반대로 더 적합한 타사 보장으로 이동할 수 있으며, 그 감소가 전부 경쟁사의 이익이 되는 것도 아니다. 고객의 비용 절약이 포함되기 때문이다.

수익은 주로 적합한 보험계약을 인수·유지하며 얻는 보험 경제성과 관리비용 절감에서 나온다. AI 문의당 별도 요금을 받을 수 있다고 가정하지 않는다. 정당한 보험금 지급을 늦추거나 부적합 계약을 유지시켜 만든 지표는 성공이 아니다. 고객 목적 해결, 청구·변경 완료, 담당자 인계, 민원과 계약당 총관리원가를 함께 확인한다. 합병은 공통 운영 역량을 재사용할 기회지만, 병행 시스템 비용이 줄지 않으면 내부 통합 가설을 낮춰야 한다.

### 2. 증권: 반복 발행·집행·사후관리 계약부터 확보하고 종투사 확장을 연결

기존 중개 고객의 주문·증거금·통화·출금, 기존 발행인의 반복 조달을 출발점으로 삼는다. 고객 AI에는 유효한 가격, 적격성, 권리, 총비용, 실제 사용 가능한 현금 시점과 실패 복구를 제공한다. 해외 상품을 하나 더 포장하는 것보다 동일 목적을 가장 낮은 총비용으로 끝내는 능력이 중요해진다.

비정형 RWA의 예로 특정 출판사의 검증 가능한 확정 정산채권을 가정할 수 있다. 문고는 실제 계약과 정산 사실에 관한 정보를 적법하게 제공하고, 증권은 채권 양도·반품·상계·담보 순위·수금 통제를 검토한 뒤 투자자와 연결한다. 투자자 돈은 계약상 발행주체·매도자에게, 채무자의 지급은 정해진 수금·배분 경로로 흐른다. 증권의 보수는 주선·배포·관리 계약에 따른다. 문고의 고객 데이터나 모든 IP가 그룹 소유의 금융자산으로 자동 전환되지는 않는다.

원래 수작업 고정비 때문에 조달액이 작아 거래를 못 했던 출판사가, 같은 권리 품질과 위험을 유지하며 비용을 감당할 수 있게 된다면 **새로운 금융 접근**이다. 그러나 기존 팩토링을 토큰으로 바꾼 것만으로 순신규 금융수요가 생기지는 않는다. 차입자의 지급능력, 권리의 불확실성, 투자자 수요가 병목이면 고정비 감소만으로 해결되지 않는다. 법인별 보증·인수 부담이 추가되면 수수료와 별도로 자본·손실 비용을 심사한다.

### 3. 그룹: 같은 고객 업무에서 공통 기준만 연결하고 외부 대안과 경쟁시킨다

생명 기관 운용에서 요구하는 통화·현금 일정·투자자격·담보·보고 기준을 증권의 기관 서비스와 비교한다. 공통 기준을 재사용할 실익이 있으면 연결하되, 생명은 독립 투자심사와 ALM을 유지한다. 생명이 증권 상품을 매입했다는 사실만으로 외부 고객 수요나 그룹의 새 수익이 생겼다고 보지 않는다. 계열 간 보수 이전은 그룹 내부 이동이며, 외부 고객의 추가 보수나 실질 비용 절감과 분리해야 한다.

USDC·USDT 중 하나를 먼저 정하기보다 거래 통화·상환·현금 사용 시점·환율·준비자산·상대방·복구 조건으로 경로를 고른다. 현재 관측된 교보 접점은 USDC 관련 시연과 별도의 엔·원 테스트를 포함한다. 미래에도 엔·원 거래는 직접 경로가 더 나을 수 있고, 달러 자산 거래에는 다른 경로가 맞을 수 있다. 범용 지갑·체인·환전 연결은 외부 구매를 기본 비교안으로 두고, 실제 반복 수요와 자체 운영의 비용 우위가 증명될 때 투자 범위를 넓힌다.

## 5. 중요한 조건을 뒤집으면 행동도 바뀌는가

| 반사실 | 고객·돈·보수의 변화 | 교보의 대응 |
|---|---|---|
| 같은 2027년, 교보는 적응하지 않고 경쟁사가 같은 상품 정보와 실행을 더 싸게 제공 | 고객 AI가 경쟁 채널을 선택해 표준 중개·판매 보수가 줄고, 일부 보장·계약관리는 남더라도 비싼 관리비가 이익을 압박 | 단순 정보·연결의 독자 구축을 줄이고 외부 기술 구매, 계약관리 품질·전문 발행 업무에 집중 |
| 같은 2027년, 교보가 적응했으나 경쟁사도 같은 품질·가격을 제공 | 교보의 개선만으로 점유율·마진 증가가 보장되지 않는다. 비용 절감 편익이 고객에게 이전될 수 있다 | 유지·확대 여부를 점유율보다 고객 업무당 총비용 후 기여와 손실·민원으로 결정. 남는 우위가 없으면 해당 범위 축소 |
| 기존 계좌·전자증권+AI로 같은 목적을 완료 | 비교·권한 확인·보고·계약관리는 개선되나 온체인 추가 보수의 이유는 약함 | 이 기준선을 우선 운영. ‘체인 미도입’을 실패로 보지 않음 |
| 여러 기관의 공동 상태·조건부 이전이 필요하고 AI+온체인이 대사·대기·오류 비용을 더 낮춤 | 발행·수탁·현금 공급자의 비용 배분이 바뀜. 즉시 결제에 필요한 선자금·담보 비용이 절감을 상쇄할 수도 있음 | 같은 고객·권리·통화·기간·위험 기준으로 순편익을 확인한 업무만 추가 |
| 원권리 확인과 사후관리까지 표준화되어 누구나 동일 품질로 수행 | 비정형 검증 프리미엄까지 낮아짐. 기존 고객관계만으로 높은 보수 유지가 어려움 | 자체 범용 플랫폼 대신 전문 인수·복잡한 회수·투자자 목적 서비스로 좁히거나 해당 신규 사업 포기 |

## 6. 기존 판단과 비교한 갱신

| 기존 판단 | 이번 판정 | 판단을 바꾼 이유 또는 확인된 경계 | 다음 결정 관측 |
|---|---|---|---|
| 증권의 기존 거래·IB·기관 업무가 먼저다 | 유지 | 현재 지급자가 있는 업무가 출발점이며 발표·실증이 유료 외부 계약을 대체하지 못함 | 외부 반복 위임·집행 실패·정정 비용·경쟁 후 계약별 기여 |
| 그룹은 생명 장기 계약관리와 증권 실행의 두 축이다 | 유지·구체화 | 합병 선택과 기존 로보어드바이저·FP 활동은 내부 운영 효율 경로를 지지. 증권 우선순위를 그룹 전체의 유일 순위로 쓰지 않음 | 통합 후 중복 업무·시스템 비용, 고객 목적 해결과 계약 유지의 적합성 |
| 비정형 자산의 원권리 검증·신뢰가 기회다 | 조건을 좁혀 수정 | 표준화는 시장 접근을 넓히지만 검증 정보의 독점 보수를 낮출 수도 있음 | 경쟁사의 동일 권리·관리 견적, 실제 관리 위임·수금 통제·회수 원가 |
| 그룹의 기관 역량과 해외 파트너를 연결한다 | 조건부 유지 | 공통 기준의 재사용은 가능하나 계열 보조금·자동 앵커투자를 배제해야 함 | 외부 고객 보수, 계열 거래 제거 후 추가 기여, 외부 구매가격 |
| 특정 달러 레일에 탑승해 수익을 만든다 | 현재 상용 수익 판단은 보류 | USDC 접점은 시연, SBI는 별도 엔·원 테스트. USDT 실제 이용 계약은 선택 자료에서 미확인 | 법인별 서비스 계약·수취 보수·상환·최종 현금·반복 거래 |

현재 행동은 공통 계약정보와 기존 고객 업무의 원가를 정리하고, 외부 경쟁 견적을 포함한 작은 반복 업무를 검증하는 것이다. 대규모 자본 인수·단일 레일 종속·문고 전체 IP 금융화를 먼저 결정할 근거는 부족하다. 반대로 외부의 반복 계약과 위험을 반영한 기여가 확인되면 기관 발행·관리 역량에 대한 투자를 앞당길 수 있다. 모든 신사업을 본업 개선 완료 이후로 미루자는 시간 순서의 주장은 아니다.

## 확인 범위

공식 회사·거래 자문사·금융위 자료 11건의 선택 절을 확인했다. 기존 출처와의 중복을 표시했으며, 회사 설명을 독립 성과 측정으로 취급하지 않았다. 합병 원문은 웹 열람 시간초과 후 공식 URL 직접 요청으로 본문을 읽었다. 법령 상세 페이지와 DART 최근 증자 공시는 이번 웹 접근이 실패해 이전 검증을 재사용하고 미확인을 유지했다. 모든 후속 공시·계약·인가를 전수 조사한 결과는 아니다. 사용한 근거 카드에는 발표일·확인일·읽은 범위·지지하지 않는 주장이 함께 기록되어 있다.
