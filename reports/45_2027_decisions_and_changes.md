# 2027년 이후 재분석: 기존 판단에서 무엇을 유지하고 바꾸는가

2026-11-06 KST · 개선한 역할 설계 v2.1의 실제 연구 실행. 이는 전망·사업 제안이며 회사의 확정 계획이나 특정 교수의 현재 견해가 아니다.

**중심 판단은 세 그룹 모두 고객이 맡길 금융 계약과 책임을 기준으로 투자해야 한다는 것이다.** AI·온체인이 거래비용을 낮춰도 절감액은 고객, 유통 플랫폼, 대형 금융사와 나눠 가진다. 그룹의 성장 방향은 유지하되, 경쟁자도 같은 기술과 정보를 쓰는 상황에서 남는 비교우위와 총기여를 기준으로 범위를 좁혔다.

이번 변화의 대부분은 새 회사 사건을 발견해 뒤집은 것이 아니다. 기존 공식 신호를 재확인하고, 비공개로 제공된 이전 검토에서 만든 질문을 공개 근거로 검증해 인과와 실행 조건을 교정했다. 원문 대화·개인 경로·입력 파일은 게시하지 않았다.

## 2. 이번에 더 분명해진 여섯 가지

| 쟁점 | 종전 판단의 핵심 | 이번 결론과 행동 변화 |
|---|---|---|
| AI와 온체인 | 외부 AI가 고객 접점을 바꿀 수 있음 | **유지·강화.** 카드·기존 계좌+AI가 먼저 업무를 실행할 수 있으므로 견적·권한·처리 결과·복구를 먼저 준비. 온체인은 같은 업무의 추가 편익이 있을 때 적용 |
| 분업과 재통합 | 기능별 전문 공급·새 연결 사업 가능 | **반대 경로를 동등하게 비교.** 대형사의 내부 AI 효율과 묶음가격이 더 강하면 표준 기술은 구매하고 전문 기능으로 좁힘. 기능이 필요하다고 높은 보수가 남지는 않음 |
| 새 수요 | 비용 하락으로 작은 고객·발행인 접근 가능 | **조건 강화.** 기존 거절 원인이 고정비였는지 확인. 소득·신용·권리·투자자 수요가 병목이면 토큰 수를 늘려도 해결되지 않음 |
| BNK | 일상 기업금융에서 성장·전환·승계로 확장 | **방향 유지, 정보 우위와 위험 배분을 좁혀 검증.** 표준 우량거래와 비정형 관리 업무를 나누고, 외부 배분 후 예금·조달·첫 손실·후속 관리까지 평가 |
| 교보 | 생명 장기 계약관리와 증권 실행의 두 축, 비정형 RWA | **두 축 유지, 검증 독점 보수 가정 축소.** 표준화는 발행인 접근을 넓히면서 정보 프리미엄을 낮춤. 실제 수금·회수·반복 관리와 경쟁 후 원가가 남는 구간을 선택 |
| 한화 | 국내 보험·GA·ALM와 해외 거점·연결 선택권 | **일률적인 시간 순서 수정.** 국내 본업을 보호하면서 외부 계약이 성립한 해외 업무는 제한 병행. Nobu는 이미 있는 방카 채널에서 미가입 원인을 해결하는 사업으로 구체화 |

이전의 좁은 실행 순서와 넓은 그룹 성장 방향을 한 개의 순위로 섞지 않는다. 기존 STR 12개를 근거 없이 재정렬하지 않았고, 이번 판단은 별도 날짜·가정·변경 이유를 가진 추가 기록이다. 초기 여섯 가설의 정확한 유지·수정 판정은 교수형 후기와 JSON에 남겼다.

## 3. BNK: 기업의 다음 자본 사건을 맡되, 위험만 남기는 구조는 피한다

본사는 **수금·지급·FX·약정 신용 → 설비·기술 전환 → 성장·승계**를 같은 기업의 연속된 문제로 본다. 공식 산업금융·승계 조직은 이 방향을 조사할 근거지만 실현 수익의 증거는 아니다. 같은 미래차 지원에 여러 은행이 참여하고, 신한·ERP·보증기관이 기존 방식으로 채권금융을 연결한다는 점은 독점 우위 가정에 반대 근거다. [BNK 상세의 원문과 비교](42_bnk_2027_reassessment.md)

집중할 일은 세 가지다.

1. 한 산업의 실제 수금·지급·FX·한도 업무를 완결하고, 외부 AI가 선택해도 경남이 맡는 역할과 가격을 분명히 한다.
2. 그 관계에서 전환·승계 사건 한 종류를 연결해 상담 이후 계약·자금·사후관리까지 확인한다.
3. 보유·공동금융·외부 배분을 같은 위험·기간의 순기여로 비교한다. 자산 매각으로 줄어드는 조달·위험과, 포기한 수익·잔존 약정을 함께 본다.

여기서 새 기회는 원래 작은 규모 때문에 연결되지 못했던 자본 수요다. 위기는 우량 자산·예금은 경쟁자에게 넘어가고 긴급 신용·복잡한 회수만 남는 상황이다. 경쟁자가 같은 결과를 더 싸게 제공하면 범용 연결 구축을 줄이고 비용 우위가 검증된 업종·기능으로 좁혀야 한다.

## 4. 교보: 생명과 증권이 각자 선택받은 뒤 공통 기능을 재사용한다

생명은 장기 위험공동부담·유지·청구·ALM에서, 증권은 중개·발행·집행·사후관리에서 대가를 받는다. 생명 자산이나 문고 매출을 증권의 가용 자본·RWA 자산으로 합칠 수 없다. 라이프플래닛 합병 목표와 기존 로보어드바이저 활동은 내부 운영 효율의 경로를 보여 주며, DCG·Ripple·SBI·EQBR 신호는 서로 다른 실험·파트너 역할이다. USDC 관련 시연과 상용 수익을 구분한다. [교보 상세](43_kyobo_2027_reassessment.md)

집중할 일은 생명의 실제 계약 변경·유지·청구 정보를 고객 AI와 FP가 일관되게 사용하는 것, 증권의 반복 발행·집행·관리 계약을 확보하는 것, 그리고 같은 업무에서 재사용할 기준을 외부 가격과 비교하는 것이다. 종투사·초대형 IB 확장의 현재 지정·자본 인정은 별도로 확인하며, 권한이 확보된 미래에도 손실·조달·자본 제약은 남는다.

비정형 RWA의 성장 가능성은 실제 원권리를 표준화해 작은 발행인의 접근을 여는 데 있다. 동시에 표준화가 잘될수록 경쟁 중개사도 같은 자료를 사용할 수 있다. 그래서 최초 검증 자체보다 실제 수금 통제·회수·관리 계약에 어떤 차이가 남는지 물어야 한다. 문고와의 협업도 특정 출판사·채권·정산 관계에서 검증하며, 전체 IP 소유나 보험자금의 의무 매입을 전제로 하지 않는다.

## 5. 한화: 국내 장기 책임과 해외 독립 사업 위에 연결의 추가 기여를 만든다

국내 보험·GA·ALM의 규모는 작은 디지털 연결 매출과 다른 기준으로 관리해야 한다. 해외에서 Nobu의 은행·방카, Velocity의 기관 서비스, UAE의 협력·자산 연결은 각자 성립할 사업이다. 이를 하나로 연결한 추가 편익은 별도의 외부 고객·자산 위임·담보 수취·현금 공급 계약으로 확인해야 한다. Chainlink 데이터·통신 채택이 담보 인정과 대출 실행을 대신하지 않는다. [한화 상세](44_hanwha_2027_reassessment.md)

국내에서는 적합한 계약관리·정당한 청구·운영 비용에 집중한다. 인니에서는 ‘젊고 보험이 없다’는 큰 범주를 넘어, 설명·납입·청구 비용 때문에 가입하지 못했던 구체 고객군을 찾는다. 기존 Nobu 상품의 약관·가격·납입 여력부터 확인하고, 현지 통화 업무를 더 잘 해결한다면 기존 은행 시스템+AI로 시작할 수 있다.

미국·UAE의 연결에서는 모든 국가를 통과하는 거대한 망보다 이름 있는 외부 고객 업무 한 건이 먼저다. 경쟁 대형사가 같은 책임을 더 싸게 묶으면 공통 수탁·데이터·결제는 구매하고, 자산 접근·고객 유통·반복 관리에서 남는 역할을 갖는다. 외부 계약이 먼저 생긴 경우 국내 개선의 완료를 기다리느라 선택권을 놓칠 필요는 없다.

## 6. 그룹 시너지와 투자 심사의 공통 기준

‘그룹 외부 기여’는 이번 제안의 경제성을 보기 위한 비교 단위다. 공식 연결재무제표의 법적 범위와 일치한다고 가정하지 않는다. 한화·교보의 서로 다른 법인 손익을 단순 합산하지 않고, 각 법인 기여와 협업 사업의 증분을 나눈다. 같은 회계 연결 범위의 내부 보수는 제거하고, 범위 밖 법인 간 거래라도 제안의 경제적 비교에서는 같은 편익을 중복 집계하지 않는다.

같은 미래의 미대응과 적응을 비교하고 추가 투자비를 반영한다. 현재 이익보다 작다는 이유만으로 방어 투자를 버리지 않으며, 미대응해도 일어날 이탈을 모두 새 사업의 잠식으로 차감하지 않는다. 순기여에 반영한 조달·신용손실·자본 비용을 다시 빼거나 해방 편익으로 다시 더하지 않는다.

[기존 BlackRock·Ondo 비교](28_blackrock_ondo_positions.md)에서 원자산 운용, 상품 포장·유통, 수탁·상환·현금 역할을 나눈 관점을 그대로 적용했다. AI로 상품 구성이 많아져도 기초 현금흐름이나 고객의 손실 감당 능력이 같은 속도로 늘어나는 것은 아니다. 이번에는 두 회사 상품의 최신 잔액·수수료를 재조사하지 않았고, 과거 상품 조건을 새 관측으로 제시하지 않는다.

## 7. 다음 분석을 갱신할 증거

| 관측 | 판단을 강화하는 경우 | 판단을 낮추거나 바꾸는 경우 |
|---|---|---|
| 경쟁 후 고객 재선택 | 같은 권리·위험에서 더 나은 총비용·지급·관리 결과 | 같은 품질의 외부 묶음이 지속적으로 더 저렴함 |
| 새 고객의 첫 적합한 거래 | 과거 고정비 때문에 불가능했던 계약이 실제 유지·회수·지급으로 연결 | 단순 채널 이동·재포장, 또는 소득·권리·위험 병목이 남음 |
| 외부 유료 계약 | 반복 고객과 계약별 대가·운영비·손실을 확인 | MOU·테스트·계열 의무매입만 증가 |
| 자산 배분 뒤 관계 전체 | 위험·조달 부담이 실제 감소하고 관리 계약도 유지 | 좋은 자산·예금이 이탈하고 첫 손실·환매·유동성만 잔존 |
| 법·인프라 이행 | 해당 상품·법인의 권한·현금·고객 위임 성립 | 일정 도래만 확인하고 실제 계약·운영 권한은 미확인 |

현재 공개 자료만으로 고객별 순기여·가격탄력성·채택확률·사업별 온체인 이익을 확정할 수 없다. 이를 임의 수치로 채우지 않았다. 다음 실행은 새 범용 플랫폼 구축보다 기존 고객 업무의 경쟁 견적·비용·실패 기록과 작은 외부 계약을 확인하는 데 집중한다.
